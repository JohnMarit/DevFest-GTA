# DevFest Juba: City Quest

A browser game for DevFest Juba. Drive a Juba-inspired city, pick up a ride at Hai Malakal Motor Station, find Scenius Hub in Tongpiny, and clear five missions. Streets, characters, vehicles, and music are original to this game.

## Play

```bash
npm install
npm run dev
```

Open http://localhost:5173/. On a phone on the same network, use the Network URL Vite prints. Add the page to your home screen to play it full screen.

```bash
npm run build
npm run preview
```

The production build is a progressive web app (`dist/`).

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move (camera-relative on foot; throttle and steer in a vehicle) |
| Mouse | Look around. Click the city to capture the pointer |
| F | Enter or leave a vehicle |
| E | Talk, use, continue dialogue |
| Q / click | Punch. With the Pulse Pistol: click to shoot, hold right-click to aim, R to reload |
| Shift | Sprint |
| Space | Jump, or handbrake |
| Esc | Pause and map |

On a phone: drag to look, the stick moves you, and the on-screen buttons shoot, aim, talk, and ride.
